# Security policy

Keyless is at the Gate -1 mock stage. This repository does not yet store, decrypt, or forward credentials. Do not use the mock with real API keys or production data.

Once the project has a public GitHub repository, security reports should be sent through GitHub's private vulnerability reporting feature if enabled. Please do not publish unpatched security details in a public issue.

For general project support, contact [keyless@aahmedhussa.in](mailto:keyless@aahmedhussa.in). Do not send vulnerability details to the general support mailbox.

The production threat model and supported security reporting channel must be finalized before a production release. Once the public GitHub repository is available, use GitHub private vulnerability reporting if enabled.
